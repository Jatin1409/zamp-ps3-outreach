# Video script — Outreach Desk (PS-3), one take, 3 minutes

Word-for-word narration (~430 spoken words, a relaxed pace for 3 minutes). **Bold lines in brackets** are actions;
everything in quotes is what you say. One continuous screen recording with your voice: no slides, no cuts.

The runs are live and take time, so most of the talking happens *while they run* — that's how it fits in 3 minutes.
If a run finishes before you've finished a paragraph, finish the sentence and move on; if it's slower, pause.

---

## Before you press record

1. Open https://outreach-desk-lmgu.onrender.com about 2 minutes early (the free server takes ~50 s to wake).
2. Record in a **private / incognito window** so the login screen appears.
3. Close other tabs, mute notifications, browser zoom 100%.
4. No practice runs of Nithin Kamath or Sarah Riley in the hour before (free AI quota; 15 runs per hour per network).

## 0:20 – 1:40 · Happy path

**[On the card "Happy path — Zerodha's founder-CEO", click "Run live".]**

"First, the happy path: Nithin Kamath, CEO of Zerodha, run live. The seller is Ledgerline, a fictional
accounts-payable software company."

*(while it runs — speak as the stages light up)*

"Every run has a hard ninety-second limit, shown in the header, and a Stop button.

**Identity** checks it's the right person: the AI lists candidates with quotes, and code checks each quote is
really on the page — so an invented quote is simply rejected.

**Gather** collects interviews and company news. No LinkedIn scraping, only public professional information.

**Filter** removes duplicates, stale and personal items, and anything that looks like hidden instructions to an AI.

**Rank**: the AI scores relevance, but code computes the final score. And **route**: fixed rules, not the AI, decide
what happens — here, rule R7: a strong, safe signal, so it drafts."

**[The draft appears. Point at the hook title and the first line of the email.]**

"Under a hundred and twenty words, one hook, one ask. The hook's key fact had to be found word for word in the
source before it could be used — so the opening line is real, not invented. Then a swap test checks the email
wouldn't fit an unrelated prospect, so it isn't generic."

**[Click "Signals & ranking" for three seconds, then back to "Draft", then "Approve".]**

"Every signal's score, and why this one won. I approve — that only marks it ready to copy."

flagged as sensitive — never used as a hook, the tone is adjusted, and I can't approve until I confirm I've read it."

**[Tick the sensitive-context box. Approve becomes active.]**

## If something goes differently on camera

| What happens | What to do |
|---|---|
| A run is slow and you've run out of lines | Stay quiet for a moment, or say "it's running live web searches." |
| The hook is a different article than expected | Point at whatever hook is shown; the narration still holds. |
| The happy path shows "Draft with warning" | "The rules flagged something — here's why." Read the warning out. |
| A stage fails (red) | "It shows exactly what failed — it never pretends." Go back to New run and click **Replay** on the same card. |
| The 90-second limit is reached | "It hit the limit, kept what it found and marked it incomplete." Click **Run again**. |
| Running over time | Skip the "Signals & ranking" click in the happy path, and say only the first sentence of the edge-case resume lines. |
